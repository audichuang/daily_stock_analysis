# 台股波段候选流水线（量化预筛 → AI 事件面研究 → 回验）

本文是这条流水线的**唯一契约文档**：四层各自负责什么、各自被验证到什么程度、哪些结论**不**成立。
逐次研究的过程记录留在本地 `.claude/reviews/`（已 gitignore），本文只写沉淀下来的结论；
每日决策日志在 `journal/`（进版控，见 `journal/README.md`）。

> 这条流水线的产出是**候选名单与判断记录**，不是投资建议。第 1 层已被验证「机械式全收在风险
> 调整后**输给** 0050」（Sharpe 0.76~1.22 对 1.15~1.24，回撤 1.3~1.8 倍），所以任何把它当自动
> 交易讯号的用法都缺少证据支撑。

## 每天早上的固定流程（開盤前）

時間座標：台股 **09:00 開盤 / 13:30 收盤**；美股（夏令）台北時間 **21:30~04:00**；台指期夜盤到
**05:00**。所以**早上 06:00 之後**隔夜資訊已經全部到齊，07:00~08:30 是最合適的作業窗口。

```bash
make morning          # 一键：补资料 → 昨晚国际盘 → 待触发计划 → 今日候选
```

它依序做四件事，任何一件都不该跳过：

| 步骤 | 做什么 | 为什么不能省 |
| --- | --- | --- |
| ① `cli daily` | 补昨天的法人/融资/估值/大盘指数（T+1 才齐） | 只有 price 是当天写入的，其余四张早上跑才补得到 |
| ② `overnight.py` | 道琼/标普/纳指/**费半**/**台积电 ADR**/油价/汇率，带日期戳 | DB 只到昨天 13:30，之后到开盘有约 20 小时盲区 |
| ③ `verify-decisions` | **已留档、未到期**的判断：现价 vs 进场区间、失效条件 | 待触发的计划靠人记得就一定会漏 |
| ④ `make screen` | 今日候选 | — |

之後**由 agent 跑 skill `tw-swing-research`**（建议 sonnet 子代理）做第 2 层，判断追加到
`journal/swing-decisions.jsonl`，**当天 commit**：

```bash
git add journal/ && git commit -m "journal: decisions for YYYY-MM-DD"
```

脚本抓不到、仍要人工查一项：**台指期夜盘 05:00 收盘** ÷ 前一交易日现货收盘 = 开盘预期缺口
（注意 17:00~21:30 的夜盘报价不含美股资讯）。

**為什麼②不能省**：DB 只到昨天 13:30，之後到開盤有約 20 小時盲區。踩過两次——一次拿旧决策日志
充当今天的答案，一次 0 档候选就跳过隔夜检查；两次结论都碰巧对，但推导过程是坏的。

**手上有持倉時**（尚未自動化，要人工做）：逐檔對照 `journal/` 裡那筆的 `invalidation`，看論題失效
條件有沒有觸發。現行契約是固定持有 60 個交易日，**流程裡沒有賣出決策點**，所以這一步目前靠人。

**不用每天跑的**：`make verify-decisions`（60 交易日後才有到期樣本，每月看一次即可）、
`make measure` / `make portfolio`（只在改過門檻、補過歷史資料、或要重新驗證結論時跑）。

## 四层与命令

| 层 | 做什么 | 入口 |
| --- | --- | --- |
| 1 量化预筛 | 全市场扫出每天 2~5 档候选，输出 markdown + JSON | `make screen`（`scripts/screen_tw.py`） |
| 2 事件面研究 | 逐档查催化剂、判 `enter`/`pass`，写决策日志 | skill `tw-swing-research`（建议用 sonnet 子代理执行） |
| 3 分布量测 | 量讯号的前瞻报酬分布（事件级，不做部位模拟） | `make measure`（`scripts/measure_signal_forward.py`） |
| 4 回验 | 60 交易日后算这一层有没有加值 | `make verify-decisions`（`scripts/verify_swing_decisions.py`） |

组合层验证（回答「有限资金拿不拿得到」）：`make portfolio`、`make portfolio-wf`
（`scripts/portfolio_walkforward.py`）。

数据全部来自本机 Postgres `market` schema（`DATABASE_URL` 在 `.env`），爬取见
`market_data/AGENTS.md`。**价格一律经 `market.price_adjustment` 前复权**——未还原价算报酬会让
上柜除息造成约 20pp/年偏差、0050 的 1:4 分割显示 -65.79%。

## 第 1 层：冻结的讯号定义

```
日均额 ≥ 2 亿（20 日均）
排除 ETF（00xx）、TDR（91xx）、创新板（名称后缀 -创）
收盘 > 不含最近 5 天的 60 日高      # high.shift(5).rolling(61).max()
5 日涨幅 ≥ 5%
5 日／60 日量比 1.3 ~ 2.0          # 上限是同样本选模，见下方「站不住的部分」
月营收 YoY ≥ 20%                   # announce_date < 当日、且在 45 个**曆日**内
```

**live 与量测必须逐格相同**，否则量到的不是会下单的那组讯号。两个踩过的口径差：
`hi60_prior` 的视窗（实测 918 vs 894 事件、只有 859 重叠）、月营收保鲜期是 45 个**曆日**而不是
45 个**交易列**（约 63 曆日；实测 44 个 signal cell 不同，事件 973 → 974、均值 +10.47% →
+10.30%）。现在两边共用同一套定义，并有端到端验证：量测在 2026-07-24 发的讯号 = live 候选名单
`{2615, 6166}`。

排序（`score`）**只决定呈现顺序**，200 次乱序对照里没有观察到优势（见下），不要当进场理由。

## 第 3 层：讯号的前瞻报酬分布

2020-01 ~ 2026-07、扣 0.6% 来回成本、T+1 开盘买 → 第 60 个交易日收盘卖。同一档相隔 > 60 个
交易日才算新事件（名目 3,547 笔讯号只对应 974 个事件；另有 404 笔样本右端截断被排除）。

```
                       事件    均值    中位    勝率  賺賠比 两平勝率 P(≥30%) P(≤-20%) 最差
候选池                  974 +10.30% +1.13% 51.5%  2.24  30.8%  20.7%   14.6%  -55%
对等基准(同池、有月营收)7319  +5.00% -0.39% 49.1%  1.81  35.6%  12.1%   11.7%  -75%
全流动股基准           10255  +4.93% -1.01% 47.8%  1.83  35.3%  12.7%   13.2%  -75%
```

均值的 **circular block bootstrap 95% 区间 +3.66% ~ +16.93%**（block=60 交易日）。同一批事件的
IID 区间 +7.89%~+12.72% 是**假精度**——事件在时间上聚集（同一波行情、同一个产业循环），别引用。

方法上四个必要处理（每一个都是踩过之后补的）：

1. **宇宙用 `market.price` 判定，不用 `stock_info`**——后者只有现存约 1,100 档，用它过滤历史等于
   前视 + 存活偏误。**但组合层必须排除创新板**（live 的 `screen_tw.funnel` 就排除它）：不排除
   等于让组合买进 live 永远不会买的标的，而全库唯一过得了流动性门槛的 7610 是 10 倍股，
   单它一档就把 Sharpe 撑高 0.2（1.22 → 1.30），足以让结论从「落后」变成「打平」。
2. **区分样本右端截断与真下市**：前者报酬未知一律 NaN 排除（旧版把 409 笔捏造成报酬，而样本
   末端的讯号往往落在同一波行情、会整批偏向同一方向），后者必须结算（`--delisting last|zero`）。
3. **事件级去重**，且是「与上一个**保留的事件**相隔 > h」而非与上一个名目讯号相隔 > h。
4. **区块 bootstrap 的母体是完整交易日历**，circular（绕回开头）才不会让样本两端被系统性少抽。

## 组合层：有限资金拿得到吗

5 个空位、等权、固定持有 60 交易日、买卖各扣 0.30%、**排除创新板**：

```
                          年化    年化波动  Sharpe  最大回撤
组合（5 空位、全期）     +47.2%   37.4%    1.22   -45.3%
0050 买进持有（全期）    +28.6%   22.3%    1.24   -34.0%
同窗口 2021-04 起：3 空位 +45.0%／1.07／-64.7%　5 空位 +41.3%／1.07／-60.1%
                   10 空位 +32.1%／0.99／-51.8%　0050 +26.2%／1.15／-34.0%
走前选参（同窗口样本外） +24.7%   39.1%    0.76   -58.5%
```

- **资金竞争没有杀掉优势**：3,939 笔名目讯号 → 进场 130 次（已平仓 125、期末仍持有 5），另有
  372 笔落在已持股。**两侧都事件去重**后（买到的一侧因持有 60 日天然去重，没买到的一侧每天
  重复追加）：买到的 125 笔均值 +13.19%、没买到的 908 个事件 +10.34% → 排挤成本 **-2.85pp**。
  三个设定下都 ≤0（-2.85／-4.78／-0.15pp），所以右尾在 5 个空位下拿得到；也不依赖涨停成交
  假设（跳过 57 笔开盘跳空 ≥9.5% 的进场后年化 47.2% → 47.1%、Sharpe 不变）。
- **风险调整后输给 0050**：Sharpe 卡在 **0.76~1.22，没有一个赢过 0050 的 1.15~1.24**，且完全
  不随空位数改善；回撤是它的 1.3~1.8 倍。多出来的报酬是拿波动与集中度换的。
- **排序尚未观察到优势**：用 live 的公式（在**当日完整候选池**上取 pct-rank，不是剔除已持股后
  再算）对照同池乱序 **200 次**：score 期末权益 12.34x 落在乱序中位 12.82x **以下**、5~95 百分位
  8.00x~22.30x（单尾 p ≥ 0.5）。不能说已证明零价值（需要预先定义等价界线），但排名不是理由。
- **走前选参更差**：+24.7%／0.76 对同窗口冻结门槛 +41.3%／1.07。**这 16.6pp 是「两套规则的
  样本外绩效差」，不是选参偏误的规模**——这个 walk-forward 只扫三个参数，而且用事件均值选参、
  却用组合 CAGR/Sharpe 评分（目标函数错配），两者不构成 paired optimism 比较。

样本很小：125 笔（冻结）／96 笔（走前）成交、6.5 年，且冻结版有 +119.9% 来自 2026 前七个月；
资料本身处在大多头（0050 六年半 +412%）。**别外推年化。**

## 第 2 层：AI 事件面研究要做的事

量价资料看得到「涨了」，看不到「为什么涨、还能不能涨」。第 2 层要做的是分辨**催化剂可不可
延续**，具体三件事：挑出右尾（前 12% 的事件贡献总报酬 106%）、避开左尾（14.6% 的事件第 60 日
跌逾 20%）、避开主题集中（航运 34 个事件均值 +32.5%，但扣掉 2021 后 20 个只有 +1.9%、2022 起
逐年全负）。

**但要说清楚：「优势必须来自事件面研究」不是推论，是待验的假设**——第 1 层风险调整后打不赢
0050 只证明了「别拿它自动下单」，不证明事件面研究能补上那个差距，也不排除根本没有优势。

判断逐行追加到 `journal/swing-decisions.jsonl`（**进版控**，理由与栏位语意见 `journal/README.md`——`confidence` 是对未来的预测，只有在结果出来**之前**就已 commit 才有意义）。`confidence` 的语意**锁死**为「进场后第
60 个交易日收盘净报酬 ≥ +30%」的主观机率（不是「期间曾涨逾 30%」——后者基准高 15pp，语意飘掉
回验就对不上），基准率 **20.7%**。部位大小另看 `exp_upside`／`exp_downside`／`theme`：单一个
二元机率不含左尾幅度、也不含超过 30% 之后赚多少。两者是**条件均值**，期望报酬是
`upside × p + downside × (1 − p)`（**加号**，`exp_downside` 本身为负）。`decided_at` 与
`entry_range` 是回验的必要栏位：进场日取「讯号日与 `decided_at` 两者较晚者」的次一交易日，
开盘跳空穿过区间上界的那笔算**未成交**。

## 第 4 层：怎么算这一层有没有加值

`make verify-decisions` 刻意**不看命中率**——候选池本来就是正期望值，「进场的那些赚钱」证明不了
任何事，全收也会赚。三个差值才是证据：

```
E[R|enter] − E[R|全收]        选出来的比全收好多少（<0 就是这层在扣分）
E[R|pass]                     放弃掉的后来涨了多少（机会成本）
Brier(conf) vs Brier(20.7%)   confidence 有没有比「一律报基准率」更准
可成交口径                    同样 5 个空位下「全收 vs 只收 enter」两本帐
```

最后一项不可省：事件均值可以被同日同题材的一堆讯号撑高，真实帐户只拿得到 5 档。前三项的
结论一律要求 **bootstrap 区间不跨零且已到期 ≥20 笔**，否则标为 inconclusive——差值本身永远
不等于零，「>0 就有加值」是空话。未满 60 交易日列为 pending，跳空未成交单独列出。

报酬定义与第 3 层逐格一致（次一交易日开盘 → 第 60 个交易日收盘 → 扣 0.6%）。

## 站不住的部分（不要拿来当证据）

- **量比上限 2.0 是同样本选模**：去重后增量的 bootstrap 区间跨零，四格命中率去重后也不再单调。
  它站不住，只是还没有样本外资料可以替换。
- **上柜（TPEx）全无月营收**：`monthly_revenue` 的来源彙总报表只走 `/sii/`，所以营收条件实质上
  把池子限缩在上市。上柜的波段这条流程抓不到。
- **月营收有过存活偏误**：彙总报表只列目前仍在申报的公司。已用 MOPS 个别公司查询补回 5 档，
  82 档补不回（被吸收合并後回「不继续公开发行」）；最差子集併入让池子均值由 +10.30% 变
  +9.98%（**-0.33pp**），偏误真实存在但不足以翻转结论——走向下市的公司通常在跌，很少去突破
  60 日新高。
- **月营收 YoY 与命中率不单调**：20~30% 21.3%、30~50% 20.6%、50~80% 掉到 14.9%、>80% 回到 27.0%。
  「YoY 很高」本身不是理由，**它是真高还是虚高才是**。
- **创新板（-创）默认排除**：一般帐户要签风险预告书并符合资格条件才买得到。全库 25 档创新板只有
  1 档过得了 2 亿流动性门槛，而它单一笔交易就占旧版 13 年回测总损益的 85%。
- **时期依赖**：逐年只有 2022 是负的（-3.0%），但 2024 仅 +1.1%、2021 仅 +5.5%，而 2026 前七个
  月是 +37.5%——优势集中在少数年份，别当稳定溢酬。
- **组合层的 universe 用「今天的名称後缀」判定创新板**，是 PIT 板别表还没建之前的近似；方向
  保守（排除比纳入保守），但严格来说 live、事件量测、组合回测应该共用同一个 PIT universe helper。

## 可重现指令

```bash
# 前复权因子（改过 price 或补过除权息后要重跑）
uv run --env-file .env python -m market_data.cli adjust

# 第 1 层：今日候选（markdown + JSON）
make screen

# 第 3 层：分布量测（含存活偏误上界）
make measure
uv run --env-file .env python scripts/measure_signal_forward.py --survivorship-bound

# 组合层：资金竞争 / 排序检定（200 次乱序）/ 涨停敏感度 / 走前验证
make portfolio
uv run --env-file .env python scripts/portfolio_walkforward.py --rank-test 200
uv run --env-file .env python scripts/portfolio_walkforward.py --skip-limit-gap
make portfolio-wf

# 第 4 层：回验（60 交易日后才有数字）
make verify-decisions
```
