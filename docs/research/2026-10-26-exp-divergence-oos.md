# 實驗：外資與投信「橫斷面對立極端」2013–2019 樣本外驗證 2026-10-26

> 研究紀錄（快照）。構念的來源與原始數字見 `docs/tw-swing-pipeline.md`「2026-07-31 唯一从 90 臂活下来的构念」。
> 長期結論只在通過下方判準時寫進 `docs/tw-swing-pipeline.md`／`docs/tw-analysis-overview.md`。

## 0. 事先登記（跑之前寫好、先 commit）

**為什麼要做**：2026-07-31 的法人 90 臂掃描（樣本 2020-01 起）只有一個構念存活——「外資與投信同時處在
橫斷面極端、且方向相反」（分歧臂超額 +9.29% [+2.3%,+17.5%]、鏡像臂 +7.73% [+1.6%,+15.7%]、
雙中間 −3.68%）。90 臂在 5% 水準下期望約 4.5 個假陽性，所以它需要樣本外檢定。
`market.institutional` 從 2012-05 就有、構念不需要 PB，2013–2019 是乾淨的樣本外。

**假說（H1）**：2013–2019 期間，外資 20 日淨買超在橫斷面前 20% 且投信在後 20% 的股票（分歧臂），以及
方向相反的鏡像臂，前瞻報酬都高於同日共同宇宙平均；兩腿都落在中間帶的股票（雙中間臂）低於同日平均。
**H0**：這是 90 臂掃描的假陽性，樣本外不重現。

### 0.1 訊號定義

- **流向**：`market.institutional` 的 `foreign_net`、`trust_net`（單位為股，2330 抽查與 `price.volume` 同量級）。
  20 個交易日滾動加總，**正規化為 ÷ 同期 20 日成交量加總**（強度）；不正規化的原始加總做敏感度。
  兩者用哪一個當主檢定，由 §0.4 的樣本內重現步驟決定，**決定後才跑樣本外**。
- **時點**：法人資料 **lag 1 交易日**（D 日的訊號只用到 D−1 為止的法人列），與原掃描相同。
  已知與 live 不一致：`screen_tw.py` 直接吃 as_of 當日的法人列（`docs/tw-swing-pipeline.md` 已記載），本實驗不改。
- **橫斷面排名**：每個交易日在當日宇宙內做 `rank(pct=True, method="average")`。
  `> 0.8` 為前 20%、`≤ 0.2` 為後 20%、其餘為中間帶。投信有大量「20 日淨額恰為 0」的平手，
  平手取平均名次，會落在中間帶，不會被硬塞進極端。
- **臂（互斥）**：
  - 分歧臂：外資前 20% ＋ 投信後 20%
  - 鏡像臂：外資後 20% ＋ 投信前 20%
  - 同向極端：兩腿同為前 20% 或同為後 20%
  - 單腿極端：一腿極端、另一腿中間帶
  - 雙中間：兩腿都在中間帶
  - 另列單腿（外資前 20%、投信後 20%，不看另一腿）只作描述。
- **進出場**：D 日訊號、D+1 開盤進、第 h 個交易日收盤出（`measure_signal_forward.forward_returns`），
  下市以最後成交價結算（`--delisting last`）。

### 0.2 宇宙（兩個樣本窗相同）

D 日在宇宙內 ⇔ 同時符合：

1. `market.price` 當日有價格列；
2. `market_data.adjust.is_common_stock`（研究宇宙共用判斷：排除 ETF、TDR、特別股等）；
3. 20 日平均成交金額 ≥ 2 億元（與突破池同一個流動性門檻）；
4. **上市（TWSE）**：`market.institutional.market IS NULL` 的列（上櫃 `tpex` 列 2018 年才開始有，
   放進來會讓宇宙在樣本外中途改變；原掃描當時也只有上市）；且 D−1 有該檔的法人列。

### 0.3 期距、成本、統計

- **期距**：h250 是**凍結判準的決定性期距**（原構念就是用 250 日量的）；h60 依本輪研究規則同列主要期距，
  但它是**新的檢定、沒有樣本內錨點**——h60 好不能救 h250 失敗，反之亦然。h20、h10、h5（突破池研究用過的期距）只描述。
- **事件**：每一臂各自以 `measure_signal_forward.to_events` 去重（同檔 h 個交易日內算一個事件）。
  各臂互斥，且判準只比「臂 − 同日宇宙平均」，不做臂與臂的配對，所以 Codex 指出的「各自去重造成非互斥世代」問題不適用。
- **成本**：`tw_trade_costs.round_trip_return`（與 `src/services/backtest_price_basis.py` 同一真源）：
  20 萬名目本金、手續費 0.1425%（最低 20 元）雙邊、賣出證交稅 0.3%、買賣各 0.15% 滑價。
  事件與同日宇宙平均**都用淨報酬**。
- **超額**：事件淨報酬 − 同一訊號日、全宇宙所有股票的淨報酬平均（同日同宇宙超額，與原掃描同義）。
- **區間**：`measure_signal_forward.paired_block_bootstrap`，circular block、block = h、2,000 次、seed = 42。
  回報前先比對各臂事件的 `ti` 跨度與 block，跨度 ≲ block 的臂區間不可信、直接標 inconclusive。
- **時點（PIT）**：價格以 `adjust.load_factors` 前復權（`price_adjustment` 上市來源 2010 年起就有、逐年 690 筆以上）。
  **法人資料是定版值，不是盤後初版**：DB 存的是交易所最終公布數，決策當下看到的可能是初值，差異方向未知。
  構念不使用月營收，法定公告期限（`market_data/revenue_deadline.py`）不適用。

### 0.4 樣本窗與執行順序

1. **樣本內重現（保真度檢查，不是結果）**：同一份程式跑 2020-01-01 起、面板到 2026-07-24、h250，
   兩種正規化都跑。期望落在原數字附近（分歧 +9.29%／鏡像 +7.73%／雙中間 −3.68%；已知差異：
   宇宙改 `is_common_stock`、START 前訊號歸零，原 2,665→2,442 事件）。選與原數字方向、量級較吻合的正規化作為主檢定。
   若兩種都無法重現原構念的方向，樣本外結果無從解讀，整個實驗判 inconclusive。
2. **樣本外（決定性）**：訊號日 2013-01-02 起，**面板止於 2019-12-31**——前瞻報酬不得用到 2020 年以後的價格，
   以免和樣本內的報酬期重疊（h250 因此實際進場只到約 2018-12）。
3. 敏感度（不決定判定）：面板延到 2020-12-31（2019 年進場也能量到 h250，但報酬期跨進 2020）；另一種正規化。

### 0.5 判準（照 `docs/tw-swing-pipeline.md` 凍結的原文，不改）

> **判准已预先写定，不得事後挑**：分歧臂与镜像臂的样本外超额**都 > 0**，且「双中间」臂 **< 0**，
> 才算通过；只有一臂正、或阶梯消失，就当假阳性封存。

依此原文，h250 的判定分三級：

- **封存（假陽性）**：分歧臂或鏡像臂的樣本外超額點估計 ≤ 0，或雙中間 ≥ 0。
- **inconclusive**：上述三個點估計條件都成立，但分歧臂或鏡像臂的超額 block bootstrap 95% 區間跨零，
  或事件數不足（任一臂 < 100 個事件）。
- **通過**：點估計三條件成立，**且**分歧臂與鏡像臂的超額區間都排除 0，**且**兩臂的均值與 P(≥30%)
  點估計都高於同窗「共同宇宙基準」（每日都成立的宇宙格，同樣以 `to_events` 去重）。

h60 套同一組三級判準，結果單獨登錄；h20／h10／h5 只描述（P(≥30%) 在短期距幾乎為 0，不作判準）。
不論結果如何，**不改 live 篩選規則**。

命令（`DATABASE_URL` 由主 checkout 的 `.env` 於同一命令匯出、`STORAGE_DATABASE_URL=''`；唯讀）：

```
uv run --frozen python scripts/measure_inst_divergence.py --start 2020-01-01 --end 2026-07-24 --horizons 250 --norm volume
uv run --frozen python scripts/measure_inst_divergence.py --start 2020-01-01 --end 2026-07-24 --horizons 250 --norm raw
uv run --frozen python scripts/measure_inst_divergence.py --start 2013-01-02 --end 2019-12-31 --horizons 250,60,20,10,5 --norm <主檢定>
uv run --frozen python scripts/measure_inst_divergence.py --start 2013-01-02 --end 2020-12-31 --signal-end 2019-12-31 --horizons 250,60 --norm <主檢定>
```

## 2. 樣本外結果（2026-10-26 跑，主檢定 `--norm raw`）

### 2.3 次要期距（只描述）

h20／h10／h5 的雙中間超額分別 +0.10%／+0.05%／−0.04%，分歧臂 −0.34%／−0.05%／−0.02%，三個期距的凍結判準點估計都不成立。
唯一區間排除 0 的是**鏡像臂**（外資賣、投信買）：h20 +0.78% [+0.08, +1.49]、h10 +0.55% [+0.12, +0.97]、
h5 +0.30% [+0.07, +0.54]、h60 +1.47% [+0.02, +3.11]。這**不是事先登記的假說**（判準要求兩個方向一起成立），
而且是 5 個期距 × 7 臂的再一次掃描、各期距的事件高度重疊，下限都貼著 0、扣成本前後量級只有 0.3~1.5pp；
只記錄為後續若要研究「投信買、外資賣」單一方向時的起點，**不據此建任何規則**。

### 2.4 敏感度（不決定判定）

- 面板延到 2020-12-31（2019 年進場也量得到 h250，報酬期跨進 2020）：h250 分歧 +1.95% [−0.51, +4.47]、
  鏡像 +2.43% [−1.43, +6.48]、雙中間 +0.75%——同樣封存；h60 inconclusive（鏡像區間也跨零）。
- `--norm volume`：h250 分歧 −0.08%、鏡像 +6.16% [+2.74, +9.09]、雙中間 +0.58%——封存（分歧臂 ≤ 0）；
  h60 inconclusive。兩種正規化在樣本外的結論相同。

## 3. 結論與限制

- **「外資與投信橫斷面對立極端」構念在 2013–2019 樣本外沒有通過凍結的晉升判準，依規則封存**（h250 雙中間點估計 ≥ 0、階梯消失）。
  這是「沒通過事先登記的門檻」，**不是統計上的否證**：相關超額區間全部跨零，雙中間的失敗幅度落在基準自身 +1.31% 的偏移之內，統計結論是 inconclusive。
  「樣本內 +9% 來自 90 臂掃描的選擇效果加上 2020–2025 單一牛市」只是與結果相容的假說，本實驗沒有檢驗它。不改 live 篩選規則（本來就沒有用到它）。
- 限制：宇宙只有上市、每日中位 99 檔，比樣本內小一半，區間寬；封存是照事先登記規則對點估計做的處置（雙中間 ≥ 0、五臂同值），
  區間這麼寬，資料既不支持構念、也不足以排除它。法人資料是 DB 的定版值、不是盤後初值；lag 1 與 live 的 as_of 當日不一致（沿用原掃描）。
  原 `measure_inst.py` 遺失，本次以 `scripts/measure_inst_divergence.py` 重建，樣本內 raw 版重現了分歧／鏡像兩臂，
  但雙中間只有 −1.02%（原 −3.68%）。
- 重跑：`uv run --frozen python scripts/measure_inst_divergence.py --start 2013-01-02 --end 2019-12-31 --horizons 250,60,20,10,5 --norm raw`
  （程式 commit 見本檔所在分支；`DATABASE_URL` 從主 checkout `.env` 匯出、唯讀）。
