# 台股波段候選研究

量化層已經做完它能做的事。候選池的實測分布（2020-01 ~ 2026-07、**974 個事件**、扣 0.6% 成本；
同股相隔 >60 交易日才算新事件）：**均值 +10.30%、中位 +1.13%、勝率 51.5%、兩平勝率 30.8%、
P(≥30%) 20.7%（`confidence` 的錨點）、P(≤-20%) 14.6%、最差 -55%**。對等基準（同池、有月營收、
7,319 個事件）均值 +5.00%、P(≥30%) 12.1%。完整分布與 bootstrap 區間見 `docs/tw-swing-pipeline.md`
（**別引用 IID 區間**，事件在時間上聚集，那是假精度）。

**存活偏誤、組合層驗證、走前選參的結果全部在 `docs/tw-swing-pipeline.md`**，這裡不重述。只有一件
事你現在就要知道：**這一層機械式全收，風險調整後是輸給 0050 的**（Sharpe 0.76~1.22 對 1.15~1.24，
回撤 1.3~1.8 倍），而「事件面研究能補上那個差距」是**待驗假設**，不是已經證明的事。你的判斷會被
回驗，包含可成交口徑（同 5 個空位下「全收 vs 只收 enter」兩本帳）。三件事是重點：

1. **挑出右尾**：**前 12% 的事件貢獻總報酬的 106%**（其餘 88% 合計為負），拿掉 29 個報酬
   >100% 的事件後均值從 +10.3% 掉到 **+5.9%**。中位只有 +1.1%。
2. **避開左尾**：14.6% 的事件第 60 日收盤跌逾 20%，單筆最差 -55%。可延續的催化劑與已被消化
   的題材，事後看起來一樣，事前只有事件面研究分得出來。
3. **避開集中**：期望值在時間與產業上都不均勻。逐年只有 2022 是負的（-3.0%），但 2024 僅
   +1.1%、2021 僅 +5.5%，而 2026 前七個月 +37.5%——優勢集中在少數年份。航運（產業代碼 15）
   34 個事件均值 +32.5%，但 2021 那 14 個是 +76.2%，**其餘 5 年的 20 個只有 +1.9%、勝率 45%**
   （低於全池的 52%），2022 起逐年全負。同一個主題連續放行就是在押單一循環。

**定量,不是逐檔否決。** 期望值為正的池子裡,把每一檔都打回去等於丟掉機會——`E[R|pass]`
（放棄掉的後來漲多少）跟 `E[R|enter]` 一樣會被回驗。三種情況才 `pass`：**查無催化劑**、
**催化劑屬一次性**（見下表），或 **Step 4 的預期報酬為負**。

## 你在找的東西：催化劑

量價資料能看到「漲了」，看不到「為什麼漲、還能不能漲」。那個「為什麼」就是**催化劑**，
而分辨它**可不可延續**是這份工作的全部價值：

| 催化劑類型 | 可延續 | 辨識線索 |
| --- | --- | --- |
| 訂單／客戶（新客戶、拉貨、轉單） | 是 | 客戶具名、後續季度有量、法說有提 |
| 產業循環（報價、缺貨、庫存回補） | 是 | 同業一起動、報價指數同步 |
| 產品／技術（新產品、認證、規格升級） | 是 | 有時程與客戶，不是只有新聞稿 |
| 事件（併購、分拆、資產處分、政策） | 視個案 | 一次性金額 vs 改變獲利結構 |
| 一次性（匯兌、業外、低基期） | **否** | 去年同期異常低、獲利來自業外 |

月營收 YoY 高不代表催化劑可延續——**低基期造成的 YoY 跳增最常見，也最沒有續航力**。
候選池的實測命中率對 YoY **不單調**：20~30% 那格 21.3%、30~50% 20.6%、50~80% 掉到 **14.9%**、
>80% 又回到 27.0%。所以「YoY 很高」本身不是理由，**它是高還是虛高才是**。

## Step 0：隔夜盤 + 取得候選（兩件都要，隔夜盤先做）

### 0a. 先查昨晚的國際盤（**無條件執行**）

**DB 給你的是台股昨天 13:30 以前的世界**，那之後到今天開盤還有約 20 小時。只用 DB 下的任何結論，
都是拿過期資訊決定今天的動作。所以這一步在**看候選數量之前**做完，而且：

> **候選 0 檔不是跳過隔夜盤的理由。** 它還決定另外兩件事：**已留檔但待觸發的計畫**（例如
> 「回落到 X~Y 且費半止穩才重看」）今天成不成立，以及使用者問「今天大盤會怎樣」時你憑什麼回答。
> 踩過：0 檔候選就直接回「今天沒東西買」，沒查昨晚美股——結論碰巧對，推導過程是壞的。

至少要拿到這五個數字，**每個都附來源連結**，查不到就明寫「查無」，不要用推測補：

| 要查 | 為什麼 |
| --- | --- |
| 道瓊／標普／那斯達克收盤幅度 | 分辨「全面承壓」還是「資金在族群間輪動」 |
| **費半（SOX／SMH）** | 台股是半導體權重市場，這一個指標的解釋力高於大盤三兄弟 |
| **台積電 ADR** | 折算台積電開盤價；它一檔就佔加權指數約三成權重 |
| 台指期**夜盤收盤**（05:00） | ÷ 前一交易日現貨收盤 = 開盤預期缺口 |
| 油價／匯率／地緣 | 對非電子族群（航運、傳產、內需）的方向常與電子相反 |

**時點陷阱（實際踩過）**：台指期夜盤 17:00 就開始，但美股（夏令）21:30 才開盤——**17~21 點之間的
夜盤報價完全不含美股資訊**。查到的數字一定要確認是「美股收完之後」的，否則你會拿一個作廢的
+311 點去算開盤缺口。同理，搜尋結果常把上週五與昨天的收盤混在一起，**先對日期再引用**。

**完成條件**：五個數字（或明寫查無）+ 來源連結，並用一句話說出「今天的壓力集中在哪個族群、
哪個族群反而有支撐」——不是只給一個「漲/跌」。

### 0b. 取得候選

```bash
make swing                            # 更新台股資料 → 全市場篩選 → 產出候選 JSON
make screen TOP=40 MIN_TURNOVER=1     # 只想放寬門檻時（會納入中小型股，注意出場流動性）
uv run --env-file .env python scripts/screen_tw.py --date 2026-07-24 --json /tmp/c.json
                                      # 指定基準日做回顧掃描（SQL 已加 <= as_of 上界，不會讀到未來）
```

候選 JSON 在 `.claude/reviews/screen-tw-latest.json`，人類可讀版在同目錄的 `screen-tw-<date>.md`。

**先看報告第 0 節的資料新鮮度**：基準日是不是最近一個交易日、當日檔數是否約 2,300+。落後就先跑
skill `update-market-data` 補資料再回來。**盤前做研究時基準日必然是前一個交易日**——台股 13:30
收盤、法人與融資 T+1 才補齊，所以今天早上拿到的是昨天收盤的訊號，你要判斷的是「今天開盤要不要買」。

## Step 1：讀候選

從 Step 0 的 JSON 讀 `candidates`。每檔的 `why_selected` 已寫明它憑
什麼進名單（突破幅度、5 日漲幅、量比、月營收 YoY）。

**完成條件**：你能用一句話說出每一檔進名單的理由，並記下 `break_pct`、`d5`、`vol_ratio5`、
`yoy`、`inst_streak` 五個數字——後面的判斷要拿它們跟你查到的消息對時間。

## Step 2：找催化劑

逐檔搜尋，目標是**具名的催化劑加上發生日期**。查得到什麼就寫什麼，查不到就寫「查無」。

- 公司近一個月的重大訊息、法說會、月營收公告的說明
- 突破那幾天（用 Step 1 記下的日期往前推 5~10 天）有什麼新聞
- 產業層：報價、同業營收、客戶端的財報或展望
- 同業有沒有一起動（可直接查本機 DB，`market.price` + `market.stock_info` 的 industry）

**完成條件**：每檔都有「催化劑一句話 + 發生日期 + 類型（上表五類之一）+ 來源連結」，
或明確的「查無催化劑」。

## Step 3：反面證據

對每檔回答四個問題。這一步決定通過率，不要跳。

1. **消化度**：催化劑見報幾天了？股價已經反映多少？`break_pct` 與 `d5` 是在消息之前
   還是之後？消息後才漲的，追價空間已經被吃掉一部分。
2. **籌碼**：`inst_streak`／`inst_5` 是法人連續買超，還是散戶融資推的？`margin_chg5` 為正
   而法人沒買，代表籌碼結構偏弱。
3. **同業**：同業一起動 → 產業循環，可延續；只有它動 → 個別事件，要確認是實質而非題材。
4. **行事曆與隔夜**：未來 5 個交易日的財報／法說／除權息／FOMC（事件密集就降部位，不要在事件
   前一天重倉）。隔夜數字用 Step 0a 已經查好的，兩條可判定的規則：**台指期夜盤收盤 ÷ 前一交易日
   現貨收盤 = 開盤預期缺口，所有價位照這個比例修正**；**費半跌逾 2% 時，`semi_linked` 為 true
   的標的優先剔除，不管分數多高**。
5. **同產業近期訊號表現**：查本機 DB，這個產業近 12 個月觸發過幾個**事件**（同股 60 交易日
   內的重複觸發算一個）、後續第 60 日收盤的結果如何。歷史產業均值被單一舊循環撐起來是常態：
   航運扣掉 2021 之後 20 個事件只有 +1.9%、勝率 45%，2022 起逐年全負。**看近期，不看全期。**

**完成條件**：五個問題每檔都有答案，`semi_linked` 的標的必須寫明最近一盤費半表現，
且產業近 12 個月的訊號結果有具體數字（沒有訊號也要寫「近 12 個月無同業訊號」）。

## Step 4：判定與留檔

`pass` 的條件（其一成立即 pass）：**查無催化劑**、**催化劑屬一次性**，或**預期報酬為負**
（見下）。其餘給 `enter`。

**`confidence` 是可校準的預測欄位，不是部位大小。** 它的語意固定為「進場後**第 60 個交易日
收盤**淨報酬 ≥ +30%」的主觀機率——不是「期間曾漲逾 30%」（那個基準高 15pp，語意飄掉回驗
就對不上）。錨點：池子基準 **20.7%**；催化劑可延續 + 未消化 + 法人買超 + 同業同步 → 0.30
以上；其中任一項不成立 → 0.15~0.25。

單一個二元機率不能決定部位，因為它不含左尾幅度、也不含超過 30% 之後賺多少——而這個池子
**前 12% 的事件貢獻總報酬 106%**，形狀就是靠右尾。所以要另外填三個欄位：

- `exp_upside`：**命中時**（第 60 日收盤 ≥ +30%）的平均報酬估計，正數
- `exp_downside`：**沒命中時**的平均報酬估計，**負數**（例 -0.18 = -18%）
- `theme`：催化劑所屬主題（例：貨櫃運價、AI 伺服器、記憶體漲價）。**同一主題已有持倉時，
  第二檔起降一級部位**——池子的期望值在產業與時間上都不均勻，同主題連續放行是在押單一循環。

兩個欄位是**條件均值**，所以期望報酬就是把兩種情況加權相加：

```
E[R] = exp_upside × confidence + exp_downside × (1 − confidence)
```

**加號，不是減號**（`exp_downside` 本身已經是負的）。寫成減號會讓 `p=0.20、up=+0.45、
down=-0.18` 算出 +0.234 而放行，正確答案是 **-0.054、應該 pass**。`E[R]` 為負就給 `pass`，
不要用低 `confidence` 放行——那等於用最小部位買一個你自己認為賠錢的東西。回驗程式用的是
同一條公式，寫錯就對不上。

每檔追加一行到 `journal/swing-decisions.jsonl`（一行一個 JSON，用 append 不要覆寫；
**這個檔進版控**，欄位語意與「當天就 commit」的理由見 `journal/README.md`）：

```json
{"date":"2026-07-24","stock_id":"2615","name":"萬海","verdict":"enter",
 "catalyst":"歐洲線運價 7 月連三週上漲、SCFI 站上 2200","catalyst_date":"2026-07-18",
 "catalyst_type":"產業循環","durable":true,"digested":"partial",
 "entry_range":[85.0,88.0],"invalidation":"SCFI 連兩週回落或跌破 MA20 (82.1)",
 "peer_confirm":true,"peer_recent_12m":"航運近 12 個月 2 個事件、均值 -12%",
 "confidence":0.32,"exp_upside":0.45,"exp_downside":-0.18,"theme":"貨櫃運價",
 "decided_at":"2026-07-26T21:40+08:00",
 "reasons":["同業陽明/長榮同步走強","法人連買 6 天","PB 0.85 低於同業"],
 "sources":["https://..."]}
```

`verdict` 只有 `enter` 與 `pass` 兩種。另外補 `decided_at`（你做判斷的時點）讓資訊集可稽核。

回驗由 `make verify-decisions` 讀這個檔做：它算 `E[R|enter] − E[R|全收]`（這一層有沒有加值）、
`E[R|pass]`（放棄機會的成本）、`Brier(confidence)` 對照「一律報基準率 20.7%」，以及**可成交
口徑**（同樣 5 個空位下「全收 vs 只收 enter」兩本帳）。**單看命中率證明不了任何事——全收
也會賺**；而事件均值可以被同日同題材的一堆訊號撐高，真實帳戶只拿得到 5 檔。

`decided_at` 與 `entry_range` 是回驗的必要欄位，不是裝飾：進場日取「訊號日與 `decided_at`
兩者較晚者」的次一交易日（週五的訊號若週一晚間才研究完，用週一開盤成交等於用當天白天還
不存在的判斷下單），而開盤跳空穿過 `entry_range` 上界的那筆會被標成**未成交**而不計入。

**完成條件**：每檔一行、上述欄位齊全，且 `enter` 的每一檔都有 `entry_range`、`invalidation`、
`exp_upside`、`exp_downside`、`theme`；最後**提醒使用者把 `journal/` commit 掉**——你不能自己
commit，而這份預測只有在結果出來之前就進版控才有意義（理由見 `journal/README.md`）。

## 邊界

- 候選 JSON 的 `blind_spots` 說明資料截止在台股 13:30 收盤。所有價位都是未計入隔夜的錨點，
  進場區間要按 Step 0a 查到的隔夜盤修正。
- **量化層只負責產生候選，不負責判斷。** 它給的每個欄位都是昨天 13:30 以前的歷史值；
  催化劑、隔夜盤、產業近況都在 DB 之外，**要去查**。只把數字重新排列組合再說一遍，
  等於沒有做第二層——那正是這個技能存在的理由。
- 月營收僅上市（sii）口徑，上櫃股的 `yoy` 為 null 會在量化層就被篩掉——上櫃的波段這條
  流程抓不到，這是已知缺口。產業別同樣只有上市有值（上櫃顯示 `—`）。
- 日均額低於 2 億的標的（放寬門檻才會出現）部位要壓到「能一次市價出清」的規模，或只列觀察。
- 標籤欄的 `⚠` 是事實描述，不是自動剔除規則。
- 候選池已排除 ETF 與**創新板**（名稱後綴 `-創`）：創新板一般帳戶要簽風險預告書並符合資格條件
  才買得到，全庫 25 檔只有 1 檔過得了 2 億門檻——所以你不會在名單裡看到它們，這是刻意的。
- 排序（`score`）只決定呈現順序，而且**200 次亂序對照裡沒有觀察到它有優勢**：score 的期末
  權益 12.34x 落在亂序分布中位（12.82x）以下、5~95 百分位是 8.00x~22.30x（單尾 p ≥ 0.5）。
  這不等於已證明零價值（那需要預先定義等價界線），但**排名不是進場理由**。
- 出場交給持倉管理，不在這裡決定。實測「進場價 -10% 停損」讓單筆期望值由 +9.8% 降到
  +6.3%——先跌後漲的贏家會被砍掉，所以 `invalidation` 寫的是**論題失效條件**（催化劑破功、
  跌破結構），不是固定百分比停損。
