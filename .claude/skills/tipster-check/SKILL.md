# 社群喊單查核

使用者會貼喊單截圖問「準不準」。答案要**拿實際行情對**，不靠印象評論。

## Step 1：抄下可驗證的主張

從截圖逐條列出：發文日期（「N 天前」換成實際日期）、代號、宣稱的價位（進場價、「最新市價」、目標價與期限）、戰績（「N 檔亮燈」＝漲停）。
沒寫出場價、只寫「有望到」的，標成**不可驗證**；這本身就是結論的一部分，正好說明他的寫法怎麼講都不會錯。

## Step 2：對行情

`.env` 的 `DATABASE_URL` 是 SQLAlchemy 格式，psql 要先改掉 driver 前綴：

```bash
set -a; . ./.env; set +a; U="${DATABASE_URL/postgresql+psycopg/postgresql}"
psql "$U" -c "select stock_id,date,open,high,low,close from market.price
  where stock_id in ('2303','6217') and date between '<發文前一日>' and '<最新>' order by 1,2"
```

- 股名查代號用 `market.stock_info.name`（只有上市）；上櫃股直接用代號查 `market.price`。
- `price.change` 沒有正負號，漲跌幅一律用 `close` 相減。漲停要看兩種：收盤鎖住，或只有盤中碰過。
- 「最新市價」和 DB 最新收盤對不上時，回頭查它上一次出現那個價位是什麼時候（實例：誠美材圖上寫 13.5，實際收 31.5，上一次在那個價位是 8 個月前）。
- 目標價要換算「剩幾個交易日、還要漲幾 %」，台股單日漲跌幅上限是 ±10%。
- DB 落後時先說基準日，必要時補跑 `make morning` 的資料段。

## Step 3：判讀

逐條給「對得上／對不上／不可驗證」，再彙總：照他說的價格進場，到今天是賺還是賠。
詐騙引流的特徵，同時出現兩項以上就直說是詐騙：

- 帳號名稱是亂碼，頭像是陌生人或冒用名人
- 同一串文的最後一則導去加 LINE（「小資族群組開放」「等我訊號」「詳細上下車點位在群組」）
- 只給進場價、不給出場價；「多空關鍵」區間只是在現價上加幾 %
- 好幾個帳號共用同一套文案、點名同一批股票

最後只建議「不要加 LINE」「可以檢舉」，不要替喊單內容補分析，那等於幫它背書。
